# Weather App

A dynamic weather application built with React and Vite.

## Features
- Real-time weather updates
- Dynamic background GIFs based on weather conditions
- Responsive design

## Development

This project uses React + Vite.

### Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
