# Weather App

A dynamic weather application built with React and Vite.

## Features
- Real-time weather updates
- Automatic refresh of the currently displayed city every 10 minutes
- Manual refresh button for the active city
- Dynamic background GIFs based on weather conditions
- Responsive design

### Used "openweathermap" for the API
- https://openweathermap.org/api

## Notes
- The app now remembers the last searched city in the browser and reloads it on return visits.
- Auto-refresh happens in the browser while the page is open, so it keeps the weather data fresh without needing a full page reload.
